Proper-name BAPS-style exploratory run

Important: true BAPS software is not installed in this environment.
These outputs include BAPS-ready binary matrices plus a Dirichlet-smoothed categorical mixture proxy.
Rows are areas/localities. Features are proper-name groups. States are dominant variants per area and feature.
Filtering: at least 4 name groups and at least 10 proper-name mentions per area.
Use *_baps_binary_matrix.csv and *_feature_variant_codebook.csv as inputs/checkpoints for a real BAPS run.
